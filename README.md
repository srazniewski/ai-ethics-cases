# AI Ethics Case Library

A static, dependency-free site for browsing 20 fictionalized AI ethics cases.

## Publish with GitHub Pages

1. Create a public GitHub repository, for example `ai-ethics-cases`.
2. Upload the contents of this folder to its default branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select the default branch and `/ (root)`.
4. GitHub will publish the site at `https://srazniewski.github.io/ai-ethics-cases/` (adjust the repository name if you choose another one).

For a user-site address (`https://srazniewski.github.io/`), the repository must instead be named `srazniewski.github.io`.
